## What's new

Immich GeoTagger v1.0.9 brings a cleaner photo review, more reliable maps, and a subtle notice when a new version is available.

### ✨ Cleaner photo review

- Select photos directly on their thumbnails with a circular selection indicator
- Larger previews, more readable filenames, and a clearer matching timeline
- Consistent photo details across the review list and map views

### 🗺️ More reliable maps

- Improved map rendering in photo location views
- Fixed Android release map rendering and related build configuration
- Shared map components provide a more consistent experience

### 🖼️ Safer asset selection

- Motion photo cover files such as `.MP.COVER.jpg` are excluded from location matching and updates
- Cover files are also omitted from history
- Ordinary RAW photos, motion photos, and videos remain supported

### 🔔 Optional update notices

- A compact, dismissible notice appears on the home screen for newer stable releases
- Release pages open on GitHub; updating through Obtainium or F-Droid remains supported
- Update checks run at most once a day when opening or returning to the app
- Individual versions can be hidden, and automatic checks can be disabled in Settings
- Network failures do not interrupt tracking or synchronization

### 🧪 Reliability and maintenance

- Simplified shared preview components, map handling, and thumbnail caching
- Updated compatible patch dependencies
- Expanded automated tests for cover filtering, photo selection, and update checks
